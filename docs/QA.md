## 复现

```sh
swift run ishot-checks
./scripts/build.sh universal
./dist/ishot.app/Contents/MacOS/ishot --smoke-test
./dist/ishot.app/Contents/MacOS/ishot --capture-check
```

`--capture-check` 只在已有录屏授权时截图；未授权则输出 SKIP，不能视为 PASS。截图只在内存中处理，不保存桌面内容。`--smoke-test --output /path/to/annotated.png` 可导出示例图和应用 UI；加 `--light` 可检查浅色模式。UI 导出只捕获本应用窗口。
